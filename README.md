### What I've built

**[SparkTribe](https://github.com/Karthiikeyan/sparktribe-case-study)** · [sparktribe.in](https://sparktribe.in)  
A paid learning platform for Tamil-speaking engineering students: a 50-day DSA course, daily practice with
spaced revision, prep trackers and Razorpay checkout. I'm the founder and the only engineer.  
→ Idempotent payment fulfilment shared by checkout and webhooks, a single entitlement module for all
access decisions, and payment/coupon/referral tests against a real MongoDB instead of mocks.  
`Next.js` `TypeScript` `MongoDB` `NextAuth` `Razorpay` `Vercel`

**[SparkTime](https://github.com/Karthiikeyan/SparkTime)** · [sparktime.in](https://sparktime.in)  
My writing site, 280+ articles and five multi-part courses, running on a CMS I wrote instead of using
one. Every page is a document of an editable content type, so new sections need no code change.  
→ One SQL visibility rule behind every public read path, Postgres full-text search, owner-only admin
with OAuth + PKCE and hashed database sessions, RLS lockdown, and 700+ tests.  
`Next.js 16` `TypeScript` `PostgreSQL` `Drizzle` `Tiptap` `Vitest` `Playwright`
